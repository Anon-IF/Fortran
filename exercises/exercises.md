# 练习题集

本目录包含各章配套练习题，建议先独立完成，再参考提示。

---

## 第 1 章练习（基础入门）

**题1.1**  
编写程序，输出以下图形：
```
*
**
***
****
*****
```

**题1.2**  
编写程序，从键盘读取你的名字和年龄，输出：
```
你好，张三！你今年 20 岁。
```

**题1.3（思考）**  
不加 `implicit none` 会发生什么？下面的程序有什么问题？
```fortran
program buggy
  x = 3.14
  print *, "x =", x
end program buggy
```

## 第 2 章练习（数据类型与运算）

**题2.1**  
已知直角三角形两直角边 a=3, b=4，用 `sqrt` 计算斜边 c，并验证勾股定理。

**题2.2**  
读取摄氏温度 C，用公式 `F = C * 9/5 + 32` 转换为华氏温度。

> ⚠️ 提示：`9/5` 在整数运算中等于 1！应写成 `9.0/5.0` 或 `real(9)/real(5)`。

**题2.3**  
将以下数学表达式翻译成 Fortran 语句（x、y 均为双精度实数）：
- `z = (x² + y²)^(1/2)`
- `z = e^(x) · sin(πy)`
- `z = ln(x + √(x² - 1))`（需要 x ≥ 1）

## 第 3 章练习（选择与循环）

**题3.1**  
编写程序，判断一个年份是否为闰年（规则：能被 400 整除，或能被 4 整除但不能被 100 整除）。

**题3.2**  
用 `do` 循环计算并输出斐波那契数列的前 20 项：
```
1, 1, 2, 3, 5, 8, 13, 21, ...
```

**题3.3**  
编写程序，使用 `do while` 循环，当用户输入负数时停止，计算所有正数输入的和与平均值。

**题3.4（进阶）**  
用嵌套循环打印 9×9 乘法表，格式对齐：
```
 1×1= 1   1×2= 2  ...
 2×1= 2   2×2= 4  ...
...
```

## 第 4 章练习（数组）

**题4.1**  
声明一个长度为 10 的整数数组，给它赋值 10, 9, 8, ..., 1，然后：
- 输出数组
- 输出最大值和最小值
- 计算所有元素之和

**题4.2**  
编写程序，读取 n 个实数（n 由用户输入），用**冒泡排序**将其从小到大排序后输出。

**题4.3（矩阵运算）**  
给定两个 2×2 矩阵 A 和 B，**不使用** `matmul`，手动编写矩阵乘法，输出 C = A×B。  
然后用 `matmul` 验证你的结果。

## 第 5 章练习（函数与子程序）

**题5.1**  
编写函数 `is_prime(n)` 返回逻辑值，判断整数 n 是否为质数。  
用它输出 1 到 100 内所有质数。

**题5.2**  
编写子例程 `sort(arr, n)`，实现选择排序（selection sort）。

**题5.3（递归）**  
编写递归函数 `power(base, exp)` 计算 base^exp（exp 为非负整数）。  
不允许使用 `**` 运算符。

---

## 第 6 章练习（文件操作）

**题6.1**  
编写程序，生成 1 到 50 的平方根数据表，写入 `sqrt_table.txt`，格式：
```
  1   1.0000
  2   1.4142
  ...
```

**题6.2**  
创建文本文件 `scores.txt`，内容为若干学生成绩（每行一个数）。  
编写程序读取文件，计算平均分，并统计高于平均分的学生人数。

---

## 参考答案提示

- 第1章：`do i=1,5` + `print "(*(a))", ("#", j=1,i)`
- 第2章：注意整数除法；`real(9)/5` 或 `9.0/5.0`
- 第3章：闰年条件：`(mod(y,400)==0) .or. (mod(y,4)==0 .and. mod(y,100)/=0)`
- 第4章：冒泡排序用嵌套循环，外层 n-1 次，内层比较相邻元素
- 第5章：判断质数：从 2 到 sqrt(n) 检查整除
