# 第 2 章：顺序结构程序设计

## 本章目标

- 掌握 Fortran 的六种基本数据类型
- 理解变量声明与赋值
- 熟练使用算术、关系、逻辑运算符
- 了解常用内置数学函数

---

## 数据类型速查表

| 类型 | 关键字 | 示例声明 | 说明 |
|------|--------|----------|------|
| 整数 | `integer` | `integer :: n` | 默认 32 位 |
| 大整数 | `integer(8)` | `integer(8) :: big` | 64 位整数 |
| 单精度实数 | `real` | `real :: x` | 约 7 位有效数字 |
| 双精度实数 | `real(8)` | `real(8) :: y` | 约 15 位（推荐） |
| 复数 | `complex` | `complex :: c` | 实部+虚部 |
| 逻辑 | `logical` | `logical :: flag` | `.true.` / `.false.` |
| 字符串 | `character(len=n)` | `character(len=20) :: s` | 最多 n 个字符 |

---

## 运算符优先级（由高到低）

| 优先级 | 运算符 | 说明 |
|--------|--------|------|
| 1（最高）| `**` | 幂运算（右结合） |
| 2 | `*` `/` | 乘、除 |
| 3 | `+` `-` | 加、减（含一元正负） |
| 4 | `==` `/=` `<` `>` `<=` `>=` | 关系运算符 |
| 5 | `.not.` | 逻辑非 |
| 6 | `.and.` | 逻辑与 |
| 7（最低）| `.or.` | 逻辑或 |

---

## 常用内置数学函数

| 函数 | 功能 | 示例 |
|------|------|------|
| `sqrt(x)` | 平方根 | `sqrt(2.0_8)` |
| `abs(x)` | 绝对值 | `abs(-3.5)` |
| `sin(x)` | 正弦（弧度） | `sin(0.0_8)` |
| `cos(x)` | 余弦（弧度） | `cos(0.0_8)` |
| `tan(x)` | 正切（弧度） | `tan(PI/4)` |
| `asin(x)` | 反正弦 | `asin(1.0_8)` |
| `acos(x)` | 反余弦 | `acos(0.0_8)` |
| `atan(x)` | 反正切 | `atan(1.0_8)*4 = PI` |
| `exp(x)` | e 的 x 次方 | `exp(1.0_8)` |
| `log(x)` | 自然对数 | `log(2.0_8)` |
| `log10(x)` | 以 10 为底的对数 | `log10(100.0_8)` |
| `int(x)` | 取整（截断） | `int(3.9) = 3` |
| `nint(x)` | 四舍五入 | `nint(3.5) = 4` |
| `real(n)` | 整数转实数 | `real(5) = 5.0` |
| `mod(a,b)` | 取余 | `mod(10,3) = 1` |

## 课后练习

1. 编写程序，读取圆的半径，输出面积和周长（使用 `acos(-1.0_8)` 计算 π）。
2. 编写程序，读取直角三角形两直角边长，用 `sqrt` 计算斜边。
3. 定义一个 `parameter` 常量 `GRAVITY = 9.8`，计算自由落体 t 秒后的速度和位移。
