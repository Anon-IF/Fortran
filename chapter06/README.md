## 本章目标

- 使用 `open` / `close` 操作文件

## 文件操作流程

```fortran
! 1. 打开文件
open(unit=10, file="data.txt", status="replace", action="write", iostat=ios)
if (ios /= 0) stop "打开文件失败"

! 2. 写入
write(10, "(f10.4)") value
write(10, *) "自由格式"

! 3. 关闭
close(10)
```

### status 参数

| 值 | 含义 |
|----|------|
| `'old'` | 文件必须已存在，否则报错 |
| `'new'` | 文件不能已存在，否则报错 |
| `'replace'` | 存在则覆盖，不存在则创建（推荐） |
| `'scratch'` | 临时文件，关闭时自动删除 |

---

## 格式描述符速查

| 描述符 | 含义 | 示例 | 效果 |
|--------|------|------|------|
| `Iw` | 整数，宽 w | `I5` | `  123` |
| `Fw.d` | 浮点数 | `F8.2` | `   3.14` |
| `Ew.d` | 科学计数法 | `E12.4` | ` 3.1416E+00` |
| `Aw` | 字符串 | `A10` | `hello     ` |
| `nX` | n 个空格 | `3X` | `   ` |
| `/` | 换行 | | |

---

## 错误处理（iostat）

```fortran
integer :: ios
read(unit, *, iostat=ios) x
if (ios > 0) print *, "读取出错"
if (ios < 0) print *, "已到文件末尾"
if (ios == 0) print *, "读取成功，x =", x
```
